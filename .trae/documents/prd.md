# Copora — 产品需求文档（PRD）

## 1. 产品概述

### 1.1 产品定位
Copora 是一款本地轻量化 Markdown 编辑阅读一体化客户端，完整复刻 Typora 全部原生能力。覆盖极简写作、学术公式排版、技术文档绘图、批量文件管理、全格式合规导出、自定义主题样式、全场景快捷键办公，全流程贴合原版操作习惯，老用户零学习成本无缝迁移。

### 1.2 产品名称
**Copora**

### 1.3 目标用户
- 原 Typora 用户（零学习成本迁移）
- 技术文档编写者
- 学术研究人员
- 程序员/开发者
- 内容创作者

### 1.4 核心价值主张
1. 所见即所得实时编辑，无传统分栏双面板
2. 完整 CommonMark + GFM 语法支持
3. 本地离线全功能可用，无强制联网
4. 跨平台统一体验（Windows / macOS / Linux）
5. 高性能渲染引擎，万字符文档秒开

## 3. 用户体验流程

### 3.1 首次启动流程
1. 启动应用 → 显示启动页（底色与原版一致）
2. 进入主界面 → 默认打开空白文档
3. 左侧文件树面板默认收起，可展开

### 3.2 核心编辑流程
1. 用户在画布中输入 Markdown 语法
2. 实时渲染为成品样式（所见即所得）
3. 光标无缝跟随排版位置
4. 支持一键切换源码模式查看/编辑原始语法

### 3.3 文件管理流程
1. 通过文件树或菜单打开文件
2. 多标签页编辑，支持拖拽排序
3. 自动保存 + 手动保存双重保障
4. 异常退出后重启自动恢复会话

### 3.4 导出流程
1. 菜单 → 文件 → 导出 → 选择格式
2. 配置导出参数（PDF 页边距、纸张尺寸等）
3. 进度条显示导出进度
4. 导出完成弹窗提示

## 4. 验收标准

1. **视觉验收：** 双屏并排对比 Typora，肉眼无任何界面、色彩、间距、动效差异
2. **功能验收：** 逐条对照本文档全部条目，全量通过，无遗漏、无简化、无逻辑偏差
3. **文档验收：** 任意复杂 MD 范文双向打开，渲染、编辑、导出、打印效果完全一致
4. **异常验收：** 断电、闪退、磁盘异常、大文件极限压力测试，容错恢复能力和原版持平
5. **体验验收：** 老 Typora 用户直接上手，无需任何适应，操作手感完全无违和
